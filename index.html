Verasol Archive Uploader

Verasol Archive Uploader is an internal tool of VerasolStudio. It copies files produced by VerasolStudio's own systems, such as build outputs and reports, into a Google Drive folder for long-term storage, and checks each copy against its checksum.

Only VerasolStudio members use it. It is not offered to the public, and there is no sign-up.

It asks Google only for the drive.file permission, which lets it see and change only the files and folders it created itself. It cannot see any other file in the Google account.
